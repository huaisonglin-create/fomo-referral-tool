# FOMO 推广业绩查询工具

BSC 链上 FOMO 代币的推广业绩 / 挖矿入金查询工具（纯前端单文件）。

## 功能
- 输入任意钱包地址，查询：本人入金 BNB、伞下所有裂变地址入金及合计、直推地址数与直推总入金、链上直推业绩、挖矿质押、完整推荐树
- 全链 1099 个参与地址全量枚举（Multicall3 聚合，本地缓存）

## 使用
直接用浏览器打开 index.html（或访问 GitHub Pages 链接），输入地址点「查询」。

## 数据口径
- 本人入金 = 挖矿合约 userInfo 质押量（累计入金 BNB）
- 直推业绩 = buyCenter.userPerformance（直接下级入金合计）
- 直推地址数 = 链上 userinvitenum
- 全部数据来自公开 BSC RPC，前端直读，无需后端

仅汇总公开链上数据，不构成投资建议。
